What it fixes

Name generators like Namelix have three problems, and most have a fourth.

Names styled as logos

They come back as fonts and colors, so you cannot read them at a glance. Here every name is plain text, the way it will be typed.

No filters

Say "8 letters or fewer, has to have 'cart' in it, .com open" and get exactly that. Length, required word, excluded word, style, and which extensions must be open.

A noisy page

No ads, no carousels, no upsell. One quiet page: names on cards, filters on top, click a name to copy it.

Fake availability

"Available" is usually a guess or a registrar's sales page. Brandrune asks the registry for that extension, in the same run, and says exactly what it answered.

How it works

  1. 1

    You describe it

    One or two sentences, in plain words, plus any rules: a length, a word it must contain, the extensions you care about.

  2. 2

    Claude writes about 150 names

    Your own Claude Code session writes them, spread across styles: compounds, blends, phrases, invented words, respellings and more. The skill holds it to names a person can say after reading once, with no suffix farming.

  3. 3

    A script asks the actual registries

    .com and .net go to Verisign. Most other extensions go to their registry's RDAP server, found through IANA's list. A few, like .io and .co, go to their registry's WHOIS. 150 names on .com take a few seconds.

  4. 4

    Only "no such domain" counts as open

    Redirects are never followed, a timeout is unknown, and each registry has to recognize a known name before any answer from it is trusted. Every answer is saved with the server that gave it and the time.

  5. 5

    You filter by talking

    "Only compounds. Drop anything with 'ly'. Both .com and .ai open." It re-filters the saved answers without asking the registries again, and redraws the page.

The status words

Every domain gets one of these, in these exact words.

StatusWhat the registry said
open $11No record, and a registrar confirmed it sells at the standard price shown. Needs a free Vercel token.
open*No record. Price not verified, so a premium or reserved name is still possible.
premiumNo record, but priced well above standard. The price is shown.
reservedNo record, but no registrar will sell it.
parkedRegistered, and parked at a domain-sale service. Often buyable from a reseller, at a markup.

Install

In Claude Code, run these two commands:

/plugin marketplace add brandrune/brandrune
/plugin install brandrune@brandrune

Then ask in plain words: "Name my app. It's a shared grocery list for roommates."

It needs Python 3.9 or newer, which macOS and most Linux systems already have. Optional: a free Vercel token turns open* into a priced open and catches premium and reserved names. Source and the manual install are on GitHub.

FAQ

Why is it free?

Because it costs almost nothing to run. Your own Claude Code writes the names, and the registries answer lookups for free. There is no server doing the work, so there is nothing to charge for. It is MIT licensed, and there is no paid tier coming.

What data leaves my machine?

The candidate names go to the domain registries that answer for them, and to Vercel's domain API only if you set a Vercel token. Your description stays in your own Claude Code session. Brandrune has no server and collects nothing. This website stores only the email you choose to give below.

Why not just ask Claude if a domain is free?

A model cannot know. It guesses from what it read in training, and short, sayable .com names get registered every day. Brandrune treats the model as the writer and the registry as the only judge.

Does it buy domains or earn referral fees?

No. It reports what the registry said. You register the name you pick, wherever you like. There are no affiliate links.

Does it check trademarks?

No. For the names you lean toward, it runs a quick web search for the name in your field and points you to the USPTO search. Clearing a trademark is your call.

Which extensions work?

.com and .net through Verisign, most others through their registry's RDAP server, and .io, .co, .sh, .me, .so and .gg through WHOIS. Extensions with neither, such as .us, .de and .co.uk, come back unknown, never open.

Do I need Claude Code?

For the naming, yes. The checker also runs on its own: python3 brandrune.py verify yourname.com.

It used to be called weavenames.

Same project, new name. Existing weavenames installs keep working, and the README has the one-time switch to the new name.
